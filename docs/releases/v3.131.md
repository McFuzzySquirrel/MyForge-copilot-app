# MyForge v3.131 — draft documentation update

**Status:** Uncommitted worktree changes; not an asserted published release.
The authoritative project change history is [updates.md](../updates.md).

## Summary

The Copilot app edition plan targets Linux for its initial evaluation; Windows
and macOS are deferred to a possible v2. The inherited standalone product
remains separate from that planned edition.

## Highlights

- Linux-first phase gates and an evidence ledger for the app edition.
- An approved investigation of workflow-owned subagents as a task execution
  route; required recovery and safety gates remain.
- Planned app-edition scope narrowed to sequential, task-scope execution;
  concurrency and phase sessions are deferred.
- User and administrator guides and an index of historical ADRs.

## Compatibility and Prerequisites

The standalone launcher manifest declares Node.js 18 or newer and identifies
package version `1.0.0-beta.6`, but its locked `@clack/prompts` dependency
requires Node.js 20.12 or newer. Git and the selected harness are needed for
their respective workflows. The app edition is not implemented.

## Installation or Upgrade

See [Getting Started](../../README.md#getting-started) and
[administration](../admin-guide.md#upgrades-and-rollback); no app-edition
upgrade path is available yet.

## Known Limitations

The Linux canvas probe is preliminary; native task dispatch and recovery have
not been established. No Windows/macOS app-edition support is claimed.
On npm `11.19.1`, seven launcher tests failed because project-scoped installs
reject `--allow-scripts`; manifest preparation using that path may fail.
The repository `LICENSE` is MIT while the launcher package manifest says ISC;
this metadata discrepancy needs maintainer review.

## Validation

On Linux with Node `24.22.2` and npm `11.19.1`, adapter tests passed
(51/51); engine tests passed (305 passed, 7 skipped). Launcher typecheck,
build and version check passed, but its test suite had 339 passes, 7 failures
and 1 skipped. See the [app evidence ledger](../copilot-app/evidence/README.md)
for probe boundaries. No app integration or release is asserted.

## Security and Privacy

The standalone Copilot adapter defaults to automatic tool approval. Keep the
Console local or behind a restricted proxy, and protect credentials and logs.
See the [administrator guide](../admin-guide.md#security-and-privacy-checklist).
