# P05: interactive authoring and plugin packaging

[Main plan](../IMPLEMENTATION-PLAN.md) | [Prerequisite](04-recovery-and-safety.md) | [Qualification](07-parity-qualification.md)

**Prerequisite:** G04. May run independently of P06 against frozen interfaces.
**Exit:** G05. **Status:** not started. **Requirements:** APP-02, APP-03,
APP-09, APP-12, APP-20. **Sources:** S-02, S-09-S-12.

## Deliverables and work checklist

- [ ] **P05-T01:** Adapt existing idea/PRD/feature authoring skills for app-native
  interaction without unattended requirements authoring. Retain canonical
  ownership, task-size validation and operator requirement review.
- [ ] **P05-T02:** Package compatible generated specialists, curated skill
  associations and compiler tooling. Validate native discovery paths, agent
  frontmatter and versioned packaging; no generic persona substitution hidden
  from the operator.
- [ ] **P05-T03:** Wire explicit brief review, preparation and deliberate build
  start through the approved app entry point. Handle fresh/existing/completed
  projects and incremental features without duplicating task definitions.
- [ ] **P05-T04:** Prepare install/update/uninstall assets using supported
  plugin conventions, with trust/permissions visible. Avoid overwrites and
  dependency/build-product copies into projects; installation does not imply
  human approval or automatic build launch.
- [ ] **P05-T05:** Update affected SKILL/reference docs and authoring usage;
  record failures for unsupported versions or missing required capabilities.
  Defer public distribution naming/channel to P08/Q06.

Outputs: installable test bundle, app authoring entry points, adapted skills/
agents, validation fixtures and updated instructions. No public marketplace
publication is authorized by this phase alone.

## Specific future sub-agent opportunities

An authoring specialist adapts selected skills; a packaging specialist owns
bundle/discovery and installation fixtures in disjoint files. A requirements
reviewer inspects canonical contracts and operator checkpoints. They consume
P04 interfaces without changing them. Coordinator handles shared skill metadata
and documentation integration; no agent marks the operator review completed.

## Validation and exit gate G05

Run V02, V03, V10 and V11 in an actual app install. Follow idea -> review ->
team -> compile -> start using reachable entry points; reject invalid sources
and missing agents. Demonstrate incremental feature continuity.

No headless requirement authoring, silent overwrite or automatic human approval.
Bundle includes only required resources; install/update/uninstall preserves
project source and accepted evidence. Existing bootstrap/authoring tests pass.

**Risks:** R05/R08/R10. **Evidence:** E-P05-* includes install manifest, source
identity, screenshots or accessible observations where useful, and real review
records with sensitive content omitted.
